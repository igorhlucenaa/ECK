# 🎨 Guia do Construtor Visual de Relatórios

## 🚀 Nova Experiência Drag & Drop

Foi criado um **construtor visual intuitivo** para montar relatórios de forma muito mais fácil e visual!

## ✨ Funcionalidades

### 1. **Interface Visual**
- ✅ Painel lateral com componentes arrastáveis
- ✅ Área central (canvas) para montar o relatório
- ✅ Painel de configuração lateral direito
- ✅ Preview em tempo real

### 2. **Drag & Drop**
- ✅ Arraste componentes da barra lateral para o canvas
- ✅ Reordene seções arrastando no canvas
- ✅ Clique nos componentes para adicionar rapidamente

### 3. **Organização por Categorias**
- 📋 **Básico**: Capa, Introdução, Resumo, Destaques, Texto Livre
- 📊 **Gráficos**: Barras, Radar, Pizza
- 📈 **Tabelas**: Frequência, Distribuição
- 🔍 **Análise**: Competência Detalhada, Defasagem, Johari

### 4. **Configuração Simplificada**
- ✅ Painel lateral que abre automaticamente ao adicionar seção
- ✅ Configuração visual e intuitiva
- ✅ Seleção de competências com multi-select
- ✅ Toggle de visibilidade

## 🎯 Como Usar

### Passo 1: Acessar o Modo Visual

1. Vá para a aba **"Montar Relatório"**
2. Selecione **"Visual (Drag & Drop)"** no toggle no topo
3. A interface visual será exibida

### Passo 2: Adicionar Seções

**Opção A - Arrastar:**
1. Encontre o componente desejado na barra lateral esquerda
2. Arraste para a área central (canvas)
3. Solte para adicionar

**Opção B - Clicar:**
1. Clique no componente na barra lateral
2. Ele será adicionado automaticamente ao canvas

### Passo 3: Configurar Seção

1. Ao adicionar uma seção, o painel de configuração abre automaticamente
2. Ou clique em uma seção existente para editá-la
3. Configure:
   - Título
   - Tipo (se necessário)
   - Competências (se aplicável)
   - Visibilidade
   - Conteúdo (se aplicável)

### Passo 4: Reordenar

1. Arraste o handle (ícone de arraste) à esquerda de cada seção
2. Solte na posição desejada
3. A ordem é atualizada automaticamente

### Passo 5: Gerenciar Seções

- **Duplicar**: Clique no ícone de copiar
- **Ocultar/Mostrar**: Clique no ícone de olho
- **Remover**: Clique no ícone de lixeira
- **Editar**: Clique na seção

## 🔄 Alternar Entre Modos

Você pode alternar entre:
- **Visual (Drag & Drop)**: Interface nova e intuitiva
- **Clássico**: Interface original (para usuários avançados)

Os dados são sincronizados automaticamente entre os modos!

## 🆘 Troubleshooting

### Componente não aparece após adicionar
- Verifique se há dados carregados (avaliação selecionada)
- Verifique o console do navegador para erros

### Drag and drop não funciona
- Certifique-se de usar o handle (ícone de arraste)
- Verifique se o Angular CDK está instalado (já está)

### Configurações não salvam
- Clique no botão "Salvar Alterações" no painel de configuração
- Ou clique em "Salvar" na barra superior
